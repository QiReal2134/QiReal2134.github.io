# HumanBlog

一个纯静态的个人主页：单页三屏左右滑动（首页 / 作品 / 关于）、灵动岛导航、深浅色主题切换、雪花飘落动效、黑灰渐变背景。无任何框架和构建工具。

**在线访问**：https://www.qireal.cn/ （经浪浪云 CDN 加速；GitHub Pages 源站为 qireal2134.github.io）

## 功能

- **单页三屏**：首页、作品、关于三屏一起渲染，点导航或左右拖动/滑动切换，带缓动动画；也支持键盘 ← → 方向键
- **作品页自动同步**：自动拉取 GitHub 账号的全部公开仓库生成卡片，并在每个仓库的 `/png` 目录下自动寻找 `background.png/jpg/jpeg/webp` 作为卡片背景图
- **作品详情页**：点击卡片进入 `work.html?repo=仓库名`，读取该仓库的 Release 展示更新日志（含日期）和下载按钮
- **缓存优先**：作品数据与详情页都先渲染本地缓存，再后台刷新，打开即有内容
- **主题切换**：深浅色切换带 1.2 秒渐变过渡，选择会记住
- **雪花动效**：Canvas 实现，页面切到后台自动暂停

## 自定义

所有可修改的内容都集中在 [config.js](config.js) 一个文件里：站点标题、Logo、头像、名字、介绍、状态、导航项、关于页内容、页脚、默认主题、作品页规则、雪花开关。改完保存刷新即可。

换头像：把自己的图片放进项目目录，然后修改 config.js 里的 `avatar` 路径。

想让某个仓库显示自定义背景图：在该仓库里建一个 `png` 文件夹，放入 `background.png` 即可。

## 本地预览

任选其一：

- 直接双击打开 `index.html`
- 或在项目目录运行 `node serve.js`，然后访问 http://localhost:8642

## 文件结构

```
index.html   单页三屏结构（首页/作品/关于）
work.html    单个作品详情页
works.html   旧地址跳转（兼容）
style.css    样式（含深浅两套主题变量 + 滑动布局）
config.js    ★ 所有可自定义内容
script.js    配置填充 + 三屏滑动导航 + 主题切换
works.js     作品列表：拉取仓库 → JSON 缓存 → 卡片渲染
work.js      作品详情：仓库信息 + Release 日志 + 下载按钮
snow.js      雪花动效
avatar.jpg   头像图片
serve.js     本地预览小服务器（可选）
```
